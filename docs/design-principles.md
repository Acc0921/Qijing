# 设计原则

## Clean-room 产品边界

公开工程只描述新产品的目标、协议和行为，不携带旧应用的包名、资源、页面命名、数据库表名、脚本格式或视觉资产。历史解析资料仅用于内部确认能力覆盖，不作为实现模板。

## 新的实现思路

1. **意图优先**：UI 提交 `CpuIntent`、`MemoryIntent` 和 `SceneProfile`，不拼接 shell 字符串。
2. **能力驱动**：先探测设备能力，再决定可用操作；厂商差异收敛在 adapter，而不是散落在页面。
3. **事务可回滚**：每次场景应用都有 task id、执行日志和 rollback command。
4. **数据与执行解耦**：C3 只保存业务意图和遥测，C0 负责把意图转换为设备操作。
5. **安全默认值**：首版使用 dry-run broker；真实特权后端必须显式启用并通过二次确认。
6. **产品化 UI**：使用单 Activity Compose、自定义信息卡和状态色，不复刻旧版页面结构。

## 公开仓库禁入项

- 旧 APK、反编译产物、旧数据库或旧配置文件。
- 旧应用包名、旧接口地址、旧脚本路径和旧品牌文案。
- 未经授权的第三方资源、在线脚本或厂商专用二进制。
